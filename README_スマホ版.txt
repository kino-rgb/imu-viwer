==============================================================
 IMU Viewer スマホ版 (Android 優先)  使い方
==============================================================

【これは何か】
 ブラウザ(Android の Chrome)で動く「アプリのようなWebページ」です。
 Arduino GIGA R1 (giga_imu_ble_v2.ino) から Bluetooth(BLE) でデータを受け取り、
   ・加速度を真上から見た図で表示(加速=緑 / ブレーキ=赤 / 旋回=青)
   ・ヨーレート・前後G・横G の時系列グラフ
   ・スマホのGPSで速度を表示し、位置も記録
   ・CSVで保存 (PC の imu_viewer_v4_1.py --replay で再生、imu_viewer_v5.py --export-map で地図化)
 ができます。計算のしかたは PC版 imu_viewer_v4_1.py と同じです。

【APK について】
 この環境では APK(インストール用ファイル)は作れません。代わりに、
 「ホーム画面に追加(インストール)」すると、アイコンから起動できてアプリのように使え、
 一度開いたあとは電波が無くても起動できます。APK が必要になったら、後から変換できます。

--------------------------------------------------------------
 手順 A: 公開する (最初の1回だけ。無料)   ※GitHub Pages を使う方法
--------------------------------------------------------------
 Bluetooth を使うページは「https で始まるアドレス」である必要があるため、
 一度ネット上に置きます。(個人データは含まれません。記録したデータはスマホの中にだけ保存されます)

 1. パソコンで https://github.com を開き、無料アカウントを作る。
 2. 右上の「+」→「New repository」→ 名前に imu-viewer と入力 → Public → 「Create repository」。
 3. 画面内の「uploading an existing file」をクリックし、この phone_app フォルダの
    次の5つのファイルをドラッグ&ドロップ → 「Commit changes」。
       index.html / sw.js / manifest.webmanifest / icon-192.png / icon-512.png
    (_source フォルダ と README は不要)
 4. 上の「Settings」→ 左の「Pages」→ Branch を「main」「/(root)」にして「Save」。
 5. 1〜2分待つと  https://(あなたのユーザー名).github.io/imu-viewer/  で開けるようになる。

--------------------------------------------------------------
 手順 B: スマホにインストールする
--------------------------------------------------------------
 1. Android の Chrome で、上のアドレスを開く。
 2. 右上の「︙」メニュー →「アプリをインストール」(または「ホーム画面に追加」)。
 3. ホーム画面の「IMU Viewer」から起動できる。次回からは電波が無くても起動する。

--------------------------------------------------------------
 手順 C: 使う
--------------------------------------------------------------
 事前: スマホの Bluetooth と 位置情報(GPS)をオンにしておく。
       Android 12 以降は「付近のデバイス」「位置情報」の許可を聞かれたら許可する。

 1. Arduino に giga_imu_ble_v2.ino を書き込み、電源を入れる。
 2. アプリで「① 接続 (Bluetooth)」→ 一覧から GIGA-IMU を選ぶ。
    ※センサー無しで画面だけ試すなら「デモ」。
 3. 「GPS: OFF → ON」を押す (位置情報の許可を聞かれたら許可)。
 4. 平らな場所で停車 → 数秒待つ → 画面に「[停止中]」と出たら「水平校正」。
 5. 走行し、カーブを数回曲がったら「向き校正」。(一度やれば、センサーを動かさない限り不要)
 6. 「● 記録開始」→ 終わったら「■ 停止して保存」。CSV が「ダウンロード」フォルダに保存される。

【うまくいかない時】
 ・「Bluetooth に対応していません」と出る → Android の Chrome で、https のアドレスから開く。
   (ファイルをスマホ内から直接開く方法では、Bluetooth が使えないことがあります)
 ・一覧に GIGA-IMU が出ない → Arduino の電源・書き込みを確認。スマホの位置情報オンを確認。
 ・「古いArduinoスケッチです」と出る → giga_imu_ble_v2.ino を書き込む (時刻付きのデータが必要)。
 ・ジャイロや向きの校正は、車が動いていると失敗します。

【iPhone について】
 iPhone の Safari は Bluetooth(Web Bluetooth)に非対応です。App Store の無料ブラウザ「Bluefy」で
 同じアドレスを開く方法がありますが、動作確認はしていません。まずは Android で使ってください。

【注意】
 ・長時間の記録(30分以上)はスマホのメモリを多く使います。分割して保存してください。
 ・記録中は画面を消さないでください(アプリは画面スリープを止めようとしますが、省電力設定で止まる機種があります)。
